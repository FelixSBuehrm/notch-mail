# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the code and not the person, and no harassment of any kind. That applies in issues, pull requests, discussions and anywhere else you represent the project.

If someone's behaviour bothers you, please tell the maintainer privately through a [GitHub security advisory](../../security/advisories/new) (it's the private channel this repo has) or via the contact on [@FelixSBuehrm](https://github.com/FelixSBuehrm)'s profile. Reports are kept confidential. The maintainer may remove comments, close threads or block people who don't respect this.
